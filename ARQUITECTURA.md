# Arquitectura del Sistema Quetzal-SPA

## Arquitectura General

El proyecto Quetzal-SPA utiliza una arquitectura por capas basada en Java y Maven.

- Interfaz HTML
- CSS
- JavaScript

### Servidor Web

- Apache Tomcat

### Servidor de Aplicación

- Maven

- Gestión de Pagos
- Gestión de Inventario
- Gestión de Reportes
- Configuración del Sistema
